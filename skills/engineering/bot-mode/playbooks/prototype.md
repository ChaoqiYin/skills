# Prototype

Run an experiment when it can settle a technical choice with less effort than further discussion. Separate product preferences from experimentally answerable questions.

1. State the uncertainty, options, and distinguishing observation. Read existing patterns before proposing alternatives.
2. Build the smallest disposable probe in isolated scratch space or an authorized working area. Preserve product code for plan-only requests. Compare candidates when a novel design needs exploration, not for every local choice.
3. Hold the workload and acceptance criteria constant across candidates. Use real inputs or representative fixtures. State the experiment's limits.
4. Run the probe, inspect output, and recommend an option supported by evidence. If inconclusive, narrow the question or report it unresolved.
5. Integrate the chosen prototype only when implementation is authorized. Collect evidence before removing task-owned disposable artifacts.

For requested independent candidates, use `arena` with actual subagents. Drafts written in one coordinator conversation do not meet that requirement.
